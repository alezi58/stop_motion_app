# Стоп-моушен студия

Простое Windows-приложение для создания стоп-моушен мультфильмов с ребенком. Оно показывает живое изображение с камеры, сохраняет кадры, показывает ленту миниатюр, удаляет выбранные кадры и собирает MP4 через FFmpeg.

Интерфейс сделан на русском языке. Основной экран сфокусирован на большом кадре, а настройки камеры спрятаны в отдельное окно «Выбрать камеру».

## Установка

Откройте PowerShell в папке `stop_motion_app` и выполните:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## FFmpeg для Windows

Для сборки MP4 нужен FFmpeg:

1. Скачайте сборку FFmpeg с https://www.gyan.dev/ffmpeg/builds/ или https://ffmpeg.org/download.html.
2. Распакуйте архив, например в `C:\ffmpeg`.
3. Добавьте папку `C:\ffmpeg\bin` в переменную среды `PATH`.
4. Перезапустите PowerShell и проверьте:

```bash
ffmpeg -version
```

Если FFmpeg не найден, приложение покажет понятную ошибку при попытке собрать видео.

## Как подключить iPhone как IP-камеру

1. Установите на iPhone приложение, которое умеет отдавать видео как MJPEG/HTTP или RTSP поток.
2. Подключите iPhone и компьютер к одной Wi-Fi сети.
3. Запустите камеру в приложении на iPhone.
4. Нажмите «Выбрать камеру» в приложении, выберите «IP-камера» и вставьте адрес потока.

Примеры адресов:

```text
http://192.168.1.23:8080/video
rtsp://192.168.1.23:8554/live
0
```

Веб-камера `0` включает тестовый режим с локальной камерой компьютера. Последний выбранный источник запоминается в настройках текущего проекта.

## Как пользоваться

1. Нажмите «Выбрать камеру» и подключите веб-камеру или IP-камеру.
2. Нажимайте «Снять кадр» после каждого маленького движения фигурки.
3. Выберите скорость ползунком от 4 до 25 кадров в секунду.
4. При необходимости включите сетку `3 x 3` или «Золотое сечение».
5. Оставьте «Показать прошлый кадр» включенным, чтобы видеть предыдущий кадр полупрозрачно поверх живой камеры.
6. Нажмите «Собрать и проиграть».

Чтобы начать другой мультфильм с пустой лентой, нажмите «Новый мульт». Старые кадры не удаляются: приложение создает новую папку проекта, например `projects/project_0001`.

Кадры сохраняются в папке текущего проекта, например `projects/default/frames` или `projects/project_0001/frames`. Готовое видео — в `output/animation.mp4` внутри этой же папки проекта. После сборки видео проигрывается внутри окна приложения.

## Тесты

После активации `.venv`:

```bash
pytest
```

Тесты проверяют создание папок проекта, создание нового проекта, запоминание текущего проекта, имена кадров, порядок кадров, удаление, настройки камеры и подготовку кадров к рендеру.

## Сборка EXE

Чтобы собрать portable-версию для Windows без установки Python:

```bash
pip install -r requirements-build.txt
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

Готовый архив появится в `release/MoyaMultistudia-v0.1.0-win64.zip`. Его можно распаковать на другом Windows-компьютере и запустить `MoyaMultistudia.exe`.

FFmpeg все равно нужен отдельно, если пользователь хочет собирать MP4. Камера, кадры и проекты сохраняются рядом с exe в папке `projects`.

## Если что-то не работает

- Нет картинки: проверьте, что iPhone и компьютер в одной Wi-Fi сети.
- Не подключается камера: попробуйте открыть URL камеры в браузере или VLC.
- Сборка видео не запускается: проверьте `ffmpeg -version`.
- Кадр не сохраняется: убедитесь, что у папки проекта есть права на запись.
- Видео слишком быстрое или медленное: измените значение «Скорость».
- Видео собрано, но не проигрывается внутри окна: откройте `output/animation.mp4` в папке текущего проекта вручную.
